# LearnTech

LearnTech is a static Af-Soomaali learning site for AI, digital skills, coding, and online-income guides.

## Project map

- `index.html` — home page, featured topics, search, and categories.
- `blog.html` — article directory.
- `*.html` — individual articles and information pages.
- `style.css` — shared visual system for article pages.
- `components/responsive.css` — shared small-screen layout and text-overflow fixes.
- `components/navigation.js` — shared, non-destructive accessibility, image, and mobile-menu behavior.
- Image files in this folder — existing blog and article images; filenames are retained so no article links break.

## Editing safely

1. Add a new article as an HTML file in this folder.
2. Use `style.css`, `components/responsive.css`, and `components/navigation.js`; do not duplicate global styles or scripts in new articles.
3. Put the article's cover image beside the article and use a meaningful `alt` description.
4. Link the article from `blog.html` or the relevant home-page category.

All original article text and image files are preserved.
